## 20-strike frontend service

### Описание

Интерфейс для моего https://github.com/def1nt/20strike-service. Отображает список компьютеров, собранную на них информацию, производит поиск.

### Компоненты

Приложение состоит из четырёх основных частей:

1. **Авторизация** — `Data/Authentication/` + `Pages/Index.razor`: вход/выход через `IAuthenticationService`, состояние авторизации `AuthenticationStateProvider`.
2. **ComputersV2** — `Data/ComputersV2/` + `Pages/ComputersV2/`: список компьютеров с пингом, расширенный поиск, подробная информация по компьютерам (маршрут `/v2/computers`).
3. **Problems** — `Pages/Problems.razor`: сканирование всех компьютеров на проблемы (маршрут `/problems`).
4. **LocationMap** — `Pages/Map/` + location-операции в `Data/ComputersV2/`: карта расположения компьютеров поверх изображения `wwwroot/images/terra.jpg` — маркеры по координатам X/Y (нормализованное пространство 0..1000), добавление (не более одного маркера на компьютер), удаление, перемещение перетаскиванием, редактирование описания, поиск с панорамированием (маршрут `/v2/map`, переход со ссылкой `/v2/map/{ComputerName}` центрирует маркер компьютера).

Подробное описание слоёв, модулей, правил зависимостей и точек расширения — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

### Запуск

Запускается любым удобным для вас и поддерживаемым .net способом, на любой платформе, способной запустить blazor server.

### Настройка

Адрес v2-бэкэнда задаётся в `appsettings.json` (секция `ComputersV2:BaseUrl`, по умолчанию `http://srv-backup:5310/v2/`).

`sample.json` — справочный пример ответа v2 API (`GET /v2/computers/{name}`), используется как документация контракта данных.
